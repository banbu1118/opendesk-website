## VDI Client 用户手册

### 一、概述

VDI Client是一款基于 Qt + FreeRDP 的 VDI 客户端。

### 二、登陆

输入服务器的ip，用户名和密码，点击登陆即可。支持英、日、中、繁多种语言登陆。

![](./images/1.png)

### 三、连接

点击连接按钮即可登陆虚拟机

![](./images/2.png)

![](./images/3.png)

鼠标靠近屏幕上方会有的悬浮工具栏显示，支持CAD(Ctrl+Alt+Del)快捷键、usb设备重定向，窗口模式。

### 四、修改用户密码

点击修改密码按钮，修改用户密码

![](./images/5.png)

### 五、操作虚拟机

点击开机，关机，重启，还原（仅还原模式配置才有）按钮后，通过刷新按钮更新虚拟机状态。虚拟机开机或重启操作后，大约10-15秒用户点击连接才能进入虚拟机，否则会提示连接失败。

### 六、用户锁定

输入5次错误密码，会导致用户被锁定，请联系管理员解锁

![](./images/6.png)
